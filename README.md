# HospitalDataAnalysis

## Description
Mini-projet d'analyse de données de patients hospitaliers.

## Objectifs
- Charger les données depuis un fichier CSV.
- Calculer des statistiques descriptives.
- Analyser les patients par sexe et diagnostic.
- Visualiser la relation entre l'âge et le cholestérol.

## Technologies
- Python
- Pandas
- Matplotlib
